# Markov Chain Simulator

## Project Overview
This project simulates Markov Chains and represents their complexities through various interactive features.

## Features
- **Simulate**: Users can run simulations of Markov Chains with customizable parameters.
- **Analytics**: Provides analytical tools to interpret results from simulations.
- **Theory**: Includes theoretical foundations of Markov Chains for educational purposes.

## Installation Instructions
1. Clone the repository: `git clone https://github.com/Harish097-afk/markov-chain-simulator.git`
2. Navigate into the project directory: `cd markov-chain-simulator`
3. Install the required dependencies: `pip install -r requirements.txt`

## Usage Guide
1. Run the application: `python main.py`
2. Follow the on-screen instructions to navigate through the features.

## Technical Details
### Weather Model Transition Matrix
The transition matrix encapsulates the probabilities of moving from one state to another in the weather model, crucial for accurate simulation outcomes.
